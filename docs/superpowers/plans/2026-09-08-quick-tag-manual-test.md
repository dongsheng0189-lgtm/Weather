# 快速標籤鍵 — 本機測試腳本

自動測試涵蓋不到瀏覽器的實際互動。這份清單的每一條，都對應開發過程中**真的發生過、
而且測試抓不到**的問題 —— 括號裡標了它守的是哪一個。

## 啟動

```bash
cd /home/hirain0126/project/webapp/app_unified
bash scripts/run_local.sh
```

開 <http://localhost:5000/dev> —— 免密登入選擇器，可一鍵切換身分。

**測試資料已備好**（`scripts/seed_quick_tags.py` 建的）：

| 店別 | 標籤 | 釘選 |
|---|---|---|
| 北店 | 陳店長知道 | ★ 會變成按鈕 |
| 北店 | 待追蹤 | ★ 會變成按鈕 |
| 北店 | 一般標籤 | 不會 |
| 北店 | 填充1～填充4 | 不會（用來測上限） |
| 南店 | 南店專用 | ★ |

> 要重置標籤資料：`../venv/bin/python scripts/seed_quick_tags.py --reset` 再跑一次不帶參數的。

## A. checklist 項目的按鈕

以 **alice**（user，北店）登入，開一張北店的 checklist 筆記（例如「客訴桌號 3」）。

- [ ] **A1**　每個項目**右側**的動作欄（`✎` `🏷️` `×` 之下）出現兩顆小方鈕，
      只顯示標籤名的第一個字：`陳`、`待`。
      「一般標籤」和「填充1～4」**不該**出現 —— 只有釘選的才有按鈕。
      （放右側而不是內容區下方，是為了不佔橫向空間、也避免與上方的已掛標籤 chip 混淆。）
- [ ] **A2**　按一下 `陳` → 立刻變成實心底色。滑鼠移上去的 title 會顯示**全名**
      （只看得到一個字，全名必須靠 hover 才認得出是哪個標籤）。
- [ ] **A3**　**同一時間，該項目上方要多出一顆同名的標籤 chip。**
      〔守 Critical：chip 列曾經完全不同步〕
- [ ] **A4**　滑鼠移到實心的 `陳` 上 → title 顯示「陳店長知道 · alice · 日期時間」。
      **對照同一項目下方的「建立/修改」時間，兩者應該是同一個時區**，
      不該差 8 小時。〔守 Important：hover 時間曾經是 UTC〕
- [ ] **A5**　**重新整理頁面** → 項目的**順序完全沒有變**，剛掛的標籤還在。
      ⚠️ **這是最重要的一條** —— 使用者交接時要逐項按，順序被打亂就沒得用了。
- [ ] **A6**　再按一下 `陳` → 變回白底外框，上方的 chip 也同步消失。
- [ ] **A7**　開一張**沒有任何標籤**的 checklist，項目的上下間距看起來正常，
      沒有多出一條空白。〔守 Important：空容器曾經佔掉 4px〕

## B. 與標籤選擇器的互動

- [ ] **B1**　用快速鍵掛上「陳店長知道」→ 接著點該項目右側的 🏷️ 按鈕。
      **選擇器裡「陳店長知道」應該已經是勾選狀態。**
- [ ] **B2**　在選擇器裡**另外**勾一個「一般標籤」→ 儲存。
      **「陳店長知道」必須still在**，不可以消失。
      〔守 Important：選擇器曾經用舊清單把它靜默刪掉〕

## C. 上限

- [ ] **C1**　用 🏷️ 選擇器把某個項目掛滿 5 個標籤（填充1～4 ＋ 一般標籤）。
- [ ] **C2**　再按 `陳` → 跳出「此項目已有 5 個標籤，請先移除其他標籤」。
      **不可以毫無反應。**

## D. 筆記層的按鈕

〔這一整區是開發過程中兩個 bug 的藏身處，原本的驗收清單沒測到〕

- [ ] **D1**　開一張**既有**筆記 → 工具列的「🏷️ 標籤 (n/5)」旁邊出現按鈕。
      **筆記層刻意顯示全名**（工具列橫向空間夠、只有一組，不像清單會重複佔位）。
      〔守 Critical：曾經因為腳本執行順序，按鈕永遠不渲染〕
- [ ] **D2**　按下去 → 變 `✓`，且「🏷️ 標籤」旁的 **(n/5) 計數要跟著加一**。
- [ ] **D3**　開**新增筆記**頁 → 按鈕**不該**出現（此時筆記還沒有 id）。
      工具列也不該因此多出一段空白。
- [ ] **D4**　在新增頁打個標題 → 按「💾 儲存」→ **不要重新整理**，
      筆記層的按鈕應該**立刻出現**。〔守 Important：曾經要重整才會出現〕
- [ ] **D5**　筆記層也做一次 B2：快速鍵掛上後，用工具列的 🏷️ 加別的標籤並儲存，
      先前那個標籤仍在。

## 出問題時

**看後端錯誤**：server 的 console 直接印出來；或
```bash
tail -f /tmp/app.log
```

**看前端錯誤**：瀏覽器按 F12 → Console 分頁。如果按鈕完全沒出現，先在 Console 打：
```javascript
window.ALL_STORE_TAGS.filter(t => t.pinned)
```
- 回空陣列 → 標籤沒釘選，跑一次 `scripts/seed_quick_tags.py`
- 出現 `undefined` → 資料沒注入進來，是 bug，跟我說

**停掉 server**：`Ctrl-C`。`run_local.sh` 下次啟動會自動殺掉佔用 5000 的舊 process。
